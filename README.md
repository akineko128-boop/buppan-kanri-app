# 物販管理アプリ

イベント・ライブ・展示会などの物販レジ管理アプリ。`index.html` をブラウザで開くだけで動く(ビルド不要・通信なし・オフラインOK)。

**イベント名・商品・価格はすべて利用者が起動後に設定します。アプリ自体には特定のイベント名や商品情報は一切含まれません。** そのため、Web公開してもアプリの中身から特定のイベント・出演者・商品情報が外部に漏れることはありません(公開する場合でも、URLを推測されにくくする・検索エンジンにインデックスさせない、といった対策は別途推奨します)。

## 初回セットアップ(利用開始前に必須)

1. 設定タブで**イベント名**(必須)・公演情報(任意)を入力
2. 「商品を追加」フォームから商品を**1つ以上**登録(商品名・価格・在庫数)
3. 「この内容でレジを開始する」ボタンでレジタブが解放される

商品が1件も登録されていない間は、レジ・履歴・集計タブはロックされ、設定タブしか使えません。

## 機能

- **レジ**: 商品タップ→カート→預かり金を電卓テンキーで入力(PCは物理キーボード可)→お釣り自動計算→会計確定(支払いは現金のみ)
- **履歴**: 取引一覧・取消(在庫は自動で戻る)・区分表示
- **集計**: 売上合計・会計数/販売点数・客単価・レジ内現金想定額・商品別販売数/残在庫
- **途中締め(販売区分)**: 集計タブの「区分を締める」で事前販売/開場後販売などを区切れる。集計は全体/区分ごとに切替表示、CSVにも区分列を出力
- **レジ締め(現金精査)**: 集計タブで金種(¥10,000〜¥1)ごとの実際の枚数を入力すると、実査合計とレジ内現金想定額(準備金+売上)を自動比較し、差額を表示する
- **商品管理**: 設定タブから商品の追加・在庫数変更・削除(販売実績が付く前のみ削除可)

## スマホ・タブレットへの導入(2通り)

- **ファイルを直接転送**: `index.html` をAirDrop/LINE/USB等で端末に送り、ブラウザで直接開く。最初の1回から通信不要で確実に動くが、ホーム画面アイコンは作りにくい(iOSは不安定、Androidもフルスクリーンにならない)
- **公開URLを開いてホーム画面に追加(推奨)**: 電波のある場所で公開URLを1回開き、共有メニューから「ホーム画面に追加」。PWA対応(`manifest.json`+`sw.js`)により、一度開けばアプリのアイコン・フルスクリーン表示になり、以降は完全オフラインで動作する

## 使い方

1. 開演前: 初回セットアップ(上記)を実施し、釣り銭準備金を入力
2. 販売中: レジタブで会計(誤操作は履歴タブから取消)
3. 終演後: 集計タブで**CSVを保存**(Excelでそのまま開ける)
4. 次のイベントで使う場合: 設定タブ「全データを初期化」でイベント名・商品・履歴をすべてリセットしてから、再度セットアップする

## 注意

- データは毎操作ごとに端末のブラウザ内 (localStorage) へ自動保存。誤ってタブ・ブラウザを閉じても、同じブラウザで開き直せば履歴・在庫・カートまで復元される
- 会計途中(カートに商品がある／預かり金入力中)に閉じようとするとブラウザの確認ダイアログが出る
- ブラウザのデータ消去(履歴クリア等)では消えるため、終演後は必ずCSVを保存すること
- データは端末ごとに独立。複数端末で使う場合は終演後にCSVを合算する
